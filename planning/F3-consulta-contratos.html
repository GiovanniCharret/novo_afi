04

Código-chave

Backend constrói o WHERE incremental (não eval, não SQL string). Frontend usa AbortController para cancelar requests stale enquanto usuário digita.

backend/app/server.py — endpoint estendido
@app.get("/api/contratos")
def list_contratos(
    request: Request, db: DbSession,
    numero: str | None = None,
    sigla: str | None = None,
    uf: str | None = None,
    tranche: str | None = None,
    tipo_contrato: str | None = None,
    com_valor: bool = False,
    incluir_inativos: bool = False,
):
    get_authenticated_user(request)
    stmt = select(Contrato)

    if not incluir_inativos:
        stmt = stmt.where(Contrato.ativo.is_(True))
    if numero:
        stmt = stmt.where(Contrato.numero.ilike(f"%{numero}%"))
    if sigla:
        stmt = stmt.where(Contrato.sigla.ilike(f"%{sigla}%"))
    if uf:
        stmt = stmt.where(Contrato.uf == uf)
    if tranche:
        stmt = stmt.where(Contrato.tranche == tranche)
    if tipo_contrato:
        stmt = stmt.where(Contrato.tipo_contrato == tipo_contrato)
    if com_valor:
        stmt = stmt.where(Contrato.valor_contrato > 0)

    rows = db.scalars(stmt.order_by(Contrato.numero.asc())).all()
    return [serialize_contrato(c) for c in rows]
frontend/src/components/ContratosBrowser.jsx — fetch debounced
function useContratos(filters) {
  const [data, setData] = useState([]);
  useEffect(() => {
    const ctrl = new AbortController();
    const tid = setTimeout(async () => {
      const q = new URLSearchParams(
        Object.entries(filters).filter(
          ([_, v]) => v !== "" && v !== false
        )
      );
      const r = await fetch(
        `/api/contratos?${q}`,
        { credentials: "same-origin", signal: ctrl.signal }
      );
      if (r.ok) setData(await r.json());
    }, 300);
    return () => { clearTimeout(tid); ctrl.abort(); };
  }, [JSON.stringify(filters)]);
  return data;
}
05

Riscos & mitigações

Risco
Sev
Mitigação
Mudar comportamento do GET /api/contratos quebra o ContratoSelector (F2) — endpoint compartilhado.
HIGH
Todos os params têm default None/False: sem params, query é idêntica à atual (WHERE ativo = true ORDER BY numero). Cobertura: adicionar teste regressivo que ataca o endpoint sem params e compara contagem.
Filtro com aspas/escape em numero ou sigla abre janela pra SQL injection se o WHERE for construído por string.
HIGH
SQLAlchemy Contrato.numero.ilike(f"%{numero}%") usa binding parametrizado — o f-string só monta o pattern do LIKE, não o SQL. Driver escapa o argumento.
Cada keystroke no campo "Buscar" dispara request. Em base de 110 contratos é negligível, mas escala mal.
MED
Debounce de 300ms + AbortController cancela request pendente quando filtros mudam. Já no snippet do código-chave.
Opções dos selects de UF/tranche são hardcoded — base nova com valores inéditos não aparece no dropdown.
MED
Derivar as opções do payload de /api/contratos sem filtros no mount inicial (ou expor GET /api/contratos/facets em fase futura). Para esta entrega, derivar client-side.
Troca de aba pra "Contratos" e volta pra "Upload" perde o estado de upload em andamento.
LOW
A aba "Upload" continua montada (apenas escondida via CSS display:none ou mantida com key estável). Validar no smoke da Fase C.
